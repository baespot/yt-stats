# YT Stats

Universal YouTube analytics tool. Fetch stats for channels, playlists, and videos.

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and add your YouTube API key:
   ```
   YOUTUBE_API_KEY=your_key_here
   ```
3. Run: `npm run dev`

## Deploy to Vercel

1. Push to GitHub
2. Import repo in Vercel
3. Add `YOUTUBE_API_KEY` in Environment Variables
4. Deploy
